# 1. Hello World

In this section we will learn about what is rust and how to code in rust. In this sections we will cover topics like:

1. Hello World - Basics introduction to Rust.
2. Comments - How to make comments in Rust
3. Formatted Print - How to Apply formating in rust.

In order to run any program in rust simply follow this above process.

1. In the command prompt go into the directory where you have kept you rust file.
2. Use the following command to generate binaries:
   
```
rustc HelloWorld.rs
```

3. Once the above code is run , then you can execute the binary using the following command:

```
./helloWorld
Hello World!
```
